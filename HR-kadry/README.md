# Sendit app
A ***Flutter*** project based on ***Provider***, ***Firebase Cloud Messaging*** and ***RESTful API*** with ***websockets*** support.

## Features
- registration and login using the SRP protocol
- full data encryption - E2EE (end-to-end encryption)
- editing profile (avatar, name and surname, email, password, online/offline status)
- adding friends, creating groups, sending messages
- push notifications
